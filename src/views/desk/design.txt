工作台页面设计内容

第一部分
1、展示合同的信息，只要展示外销合同编号、工厂合同编号、交易数量、商品编号、出口商报价、供应商报价、
出口国家、出口港、进口商国家、进口港口
2、接口可以调用 contractApi.getCurrentInfo 获取当前执行中的合同信息

第二部分
1、展示合同的执行状态，字段值是 execute_status ,有 TODO,DOING,DONE,STOPPED,FAIL 这几种状态，
用一个好看的显而易见的图标展示当前的状态
2、还有一个按钮，合同TODO显示执行合同，STOPPED、FAIL、时显示继续执行，DOING时显示停止，DONE时禁用按钮
3、执行合同接口可以调用 contractApi.executeContract，停止接口可以调用 contractApi.stopContract

第三部分
1、这部分主要显示合同执行的情况，包含执行到哪一步，然后哪些步骤还未执行，以及合同执行的日志显示
2、左边是一个Timeline 时间轴，展示合同的流程步骤，有已完成的和为完成的，已完成的节点显示绿色，未完成显示灰色，
然后右边是一个显示合同执行日志的窗口，使用类代码风格的样式显示
3、合同的流程步骤可以调用 processStepApi.listByProcessCode，获取已执行的流程步骤调用 processStepApi.getDoneProcessSteps，
获取未执行的流程步骤 调用 processStepApi.getUndoProcessSteps
合同执行日志接口调用 contractTaskHistoryApi.getLatestHistory，当合同属于DOING
状态的时候需要一直保持调用，同时其他状态不调用，注意如果页面切换需要同时把相应定时器去掉

第四部分
1、是一个列表，展示未执行的流程步骤，默认20条每页，可以调用 processStepApi.getUndoProcessSteps
这个接口获取对应的列表数据

注意：
1、要求界面简洁好看且美观，采用卡片化的设计
2、接口调用的内容都抽取到hook.ts文件里面，然后写法都采用类似以下的写法
export const useGetCurrentInfo =  () => {
  // 1.定义hooks所需数据
  const loading = ref(false)
  const currentInfo = ref<ContractInfo>({});
  const getCurrentInfo = async () => {
    loading.value = true;
    try {
      const res = await contractApi.getCurrentInfo();
      currentInfo.value = res as ContractInfo;
    } catch (error) {
      console.error('获取当前合同信息失败', error);
    } finally {
      loading.value = false;
    }
  }
  return {
    getCurrentInfo,
    loading,
    currentInfo,
  }
}
